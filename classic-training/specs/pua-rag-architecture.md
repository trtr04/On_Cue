# 普通沟通与女性 PUA 应对训练：RAG 架构 v0.2

## 核心原则

RAG 不直接在全部话术中做一次相似度搜索。系统必须先确定训练模式和独立场景模块，再对该模块允许的语料做标签过滤和相关度排序。

```text
用户选择训练模式
  ├─ ordinary（普通沟通）
  │    ├─ 当前普通场景卡
  │    ├─ 当前普通角色卡
  │    ├─ expression_references：普通表达参考
  │    └─ pressure_anti_examples：PUA 禁区反例
  │
  └─ pua_response（女性 PUA 应对）
       ├─ 一个独立 module_id
       ├─ 该模块场景卡
       ├─ 该模块压力方角色卡
       ├─ domain + scenario_types 过滤
       ├─ severity / difficulty 过滤
       ├─ 历史台词去重
       └─ controlled_pressure_examples：最多 3 条受控角色材料
```

两个模式的检索结果互斥。普通沟通不接收 `controlled_pressure_examples`；PUA 应对训练不接收普通表达参考或禁区反例。

## 语料标注

当前三份材料共解析 68 条话术：

| 来源 | 条数 |
|---|---:|
| 女性职场PUA话术.md | 10 |
| 家庭PUA话术.md | 27 |
| 职场PUA话术集合.md | 31 |

每条话术都有以下字段：

| 字段 | 作用 |
|---|---|
| `entry_id` | 稳定语料编号 |
| `source_file` / `source_heading` | 原始来源和章节 |
| `domain` | `workplace` 或 `family` |
| `scenario_types` | 可进入的一个或多个独立场景 |
| `tactic_tags` | 性别歧视、情感绑架、加班绑架、能力贬低、隐性威胁等多标签 |
| `severity` | 1 容易、2 中等、3 困难 |
| `target_group` | `women` 或 `general` |

当前标签包括：性别歧视、隐私侵犯、催婚、重男轻女、情感绑架、恐惧诉求、加班绑架、薪酬压制、能力贬低、比较施压、解雇威胁、隐性威胁、责任转移、边界侵犯、成果剥夺、人格羞辱、暴力合理化和内疚转移。

标注由 `pua_corpus.py` 的“章节标签 + 关键词多标签规则”确定。目前属于可运行的第一版，下一步仍需人工逐条复核；脚本不会把自动标签宣称为人工定论。

## 难度定义

难度同时控制“可检索语料上限”和“角色交付方式”：

| 难度 | 语料与角色行为 |
|---|---|
| 容易 | 优先使用 1 级语料；若该模块没有 1 级原句，则只提取最温和原句的压力意图并改写为表面克制的试探。禁止直接辱骂和解雇威胁。 |
| 中等 | 使用 1–2 级语料；可以直接施压，并在用户第一次设置边界后挑战一次。 |
| 困难 | 使用 1–3 级语料；可以达到该模块原始材料中的最强贬低、歧视或隐性威胁，但不得创造原材料和模块之外的新攻击。 |

难度不是把三句固定台词分别贴上标签；它同时影响检索范围、语言强度、坚持次数和边界后的松动条件。

## 每轮送给 LLM 的信息

PUA 应对训练每轮只发送：

1. 当前一个场景模块的信息。
2. 当前一个压力方角色卡。
3. 当前难度。
4. 完整对话历史和意图账本。
5. 本模块检索出的最多三条受控话术及标签。
6. 本轮尚未使用的动作白名单。

LLM 负责自然措辞；模块选择、难度上限、历史去重和动作是否已使用由服务端控制。

## 对话状态与结束条件

`max_turns=5` 是安全上限，不是要求对话必须凑满五轮。对话由服务端状态机决定是否继续，LLM 只能在当前状态允许的动作中选择并负责自然措辞。

```text
opening
  -> exchange
       -> first_boundary_challenge（最多一次）
       -> closing
  -> closed
```

| 用户最新回应 | 历史状态 | 压力方下一步 | 结束原因 |
|---|---|---|---|
| 首次明确设边界 | 尚未挑战边界 | 中、高难度可挑战一次；容易难度应直接松动 | 暂不结束或 `boundary_held` |
| 再次明确设边界 | 已挑战过或已有一次明确边界 | 承认收到立场，以陈述句结束 | `boundary_held` |
| 明确配合压力方要求 | 任意 | 确认安排，但不把顺从评价为训练成功 | `user_complied` |
| 明确要求停止或退出 | 任意 | 停止施压并结束 | `user_exit` |
| 到达最后一轮 | 尚未自然结束 | 保留决定或分歧，以陈述句结束 | `max_turns_reached` |

收口轮有四条硬约束：

- 不得提出新问题，也不能用反问句继续索取解释；
- 不得开启新的压力手法；
- 不得暴露 `move_id`、动作意图、用户分类、训练目标等内部标签；
- 必须返回 `end_session=true`，随后前端停用输入并自动生成复盘。

“坚持边界”与“说服压力方”是两种不同结果。用户无需得到压力方认同才算完成训练；当用户第二次清晰坚持边界时，状态机应把它认定为有效完成并结束，而不是继续要求用户自证。

服务端记录 `user_response_type`（`boundary`、`compliance`、`exit`、`clarification`、`self_justification`、`unclear`）和 `closure_type`。这些字段只供状态机与复盘使用，绝不能直接成为角色台词。

## 角色边界

普通沟通角色继续禁止人身羞辱、性别歧视和无缘故威胁。

PUA 应对模块不再使用这三条普通角色禁令。困难等级可以在当前模块语料范围内模拟人格羞辱、性别歧视和隐性威胁。仍然禁止：

- 跨模块增加新的攻击类型；
- 自行创造人身伤害、跟踪、报复或性暴力威胁；
- 编造用户现实经历、健康状况、违法行为或家庭事实；
- 跳出角色教学或评价用户。
